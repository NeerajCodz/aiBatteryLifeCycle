# Pre-review utilities

These scripts generated, verified, or uploaded v1/v2 and the withdrawn
pre-review v3 artifacts. They are retained for forensic reproducibility only.
They must not be used to build the reviewer-revision v3 because their feature
contracts include current-capacity or rolling-SOH target proxies.

Use the active entry points one directory above:

- `run_protocol_comparison.py`
- `run_classical_benchmark.py`
- `run_sequence_benchmark.py`
- `run_zero_shot_benchmark.py`
- `run_external_validation.py`
- `run_statistical_analysis.py`
- `generate_paper_outputs.py`
- `prepare_model_release.py`
